Cómo cambiar el robot o la web

Pedile el cambio a Claude Code sobre el repositorio de GitHub. Cuando el cambio queda en la rama main, el servidor lo detecta (cada 5 minutos), corre las pruebas y, si pasan, lo instala sin cortar una corrida en curso. Si fallan, no lo instala y queda anotado acá abajo. Para volver a la versión anterior: sudo bash /opt/monitoreo/repo/nube/actualizar_desde_github.sh --volver
